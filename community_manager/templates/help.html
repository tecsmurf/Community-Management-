How to use {{ cfg.APP_NAME }}

1. Add a family

  1. Click Families, then + New family.
  2. Enter the surname, address, area and phone, then Save. The family gets an ID like {{ cfg.FAMILY_PREFIX }}-0001.

2. Add the people in it

  1. On the family page, click + Add member. Each person gets an ID like {{ cfg.MEMBER_PREFIX }}-00001.
  2. Add the elders first (for example the grandfather and grandmother), then their children, so you can pick parents from the list.
  3. For the head of the family, choose Self (Head) as the relation.
  4. In Father, Mother and Husband / Wife, start typing a name or ID and pick from the list. You only need to set the husband/wife on one of the two; the other is linked automatically.
  5. Use Save and add another to this family to enter a whole family quickly.
  6. Leave the address blank if the person lives at the family's address.

3. Family tree

Open a family or a person and click Family tree. The tree is drawn from the father, mother and husband/wife links, so the more of these you fill in, the more complete it is. A married daughter who moved to another family still appears in her parents' tree. Click Print to print it.

4. {{ cfg.YUVAK_MANDAL_NAME }}

  • Every male member aged {{ cfg.YUVAK_MIN_AGE }} to {{ cfg.YUVAK_MAX_AGE }} gets a Yuvak Mandal ID (like {{ cfg.YUVAK_PREFIX }}-0001) automatically. A date of birth is needed.
  • A boy gets his ID automatically when he turns {{ cfg.YUVAK_MIN_AGE }}.
  • After {{ cfg.YUVAK_MAX_AGE }}, a member keeps his ID and moves to the Alumni list automatically.
  • For older men who were members in the past, open Edit and tick Was a Yuvak Mandal member in the past.
  • The Coming up this year tab shows who will join or become alumni in the next 12 months.

5. Searching and lists

  • The search box at the top finds people by name, member ID, Yuvak ID or phone. Typing a family ID opens that family.
  • On Members, filter by area, gender, profession or Yuvak status, then click Export to Excel (CSV) to get that list as a spreadsheet.
    • {% if not native_app %}
  • Any page can be printed with the Print button or Ctrl+P.
    • {% endif %}

6. Keeping the data safe

{% if online %}
  • The records are kept online, so every phone and computer that signs in sees the same data. When someone saves a change, other open screens update by themselves within a few seconds.
  • Once a week, open Backup and click Download backup, then keep that file in Google Drive or on a pen drive.
  • Admins add and remove the people who can sign in on the Users page. Change your own password by clicking your name at the top.
{% else %}
  • All data stays on this {{ 'phone' if native_app else 'computer' }}. A backup copy is made automatically every time the app starts.
    • {% if native_app %}
  • Once a week, open Backup, tap Save backup and save the file to Google Drive.
  • To move to a new phone, install the app there and use Backup → Choose backup file and restore.
    • {% else %}
  • Once a week, open Backup and click Download backup, then keep that file on a pen drive or in Google Drive.
  • To move to a new computer, install the app there and use Backup → Restore with the downloaded file.
    • {% endif %}
{% endif %}

7. Opening and closing the app

{% if online %}

Open the app's web address and sign in. To get an app icon: on an Android phone, open the address in Chrome, tap the ⋮ menu and choose Install app (or Add to Home screen). On a Windows computer, open it in Edge or Chrome and click the install icon at the right end of the address bar. It needs internet.

{% elif native_app %}

Open {{ cfg.APP_NAME }} from the phone's app list. Everything is saved on the phone as you go and works without internet. Use the phone's Back button to go to the previous page.

To move data between the phone and the computer version, save a backup on one (Backup → Save backup, for example to Google Drive) and restore that file on the other. Restoring replaces the data on that device.

{% else %}

Open {{ cfg.APP_NAME }} from the desktop icon. A small black window opens and the app appears in the web browser. Keep the black window open while working (you can minimise it). Close it when you are done. If you close the browser tab by mistake, double-click the desktop icon again.

To show the app to someone without using real records, open {{ cfg.APP_NAME }} (demo with sample data) from the Start menu. It uses a separate set of made-up families, so nothing you do there touches the real data.

There is also an Android app. A backup made here can be restored on the phone, and a phone backup can be restored here.

{% endif %}
